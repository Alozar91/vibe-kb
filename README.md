# vibe-kb — корпоративная база знаний

Централизованное хранение, учёт и поиск по корпоративным материалам, с использованием знаний в RAG-сценариях (API и MCP). Единый источник истины вместо знаний «в блокнотиках» сотрудников.

**Статус:** концепция принята (v1.0); разработка стартует с Этапа 0 (см. этапность в концепции, §18).

## Стек

Backend: Python + FastAPI · Frontend: React (TypeScript, Ant Design) · БД: PostgreSQL + pgvector · Очереди/кэш: Valkey · Хранилище файлов: Silo (S3) · Аутентификация: Keycloak (пароль / LDAP / Kerberos) · Модели: OpenAI-compatible API.
