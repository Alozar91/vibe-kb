# ADR-0005: UI-кит — Ant Design 5

**Статус:** принято · **Дата:** 2026-11-20

## Контекст

Утилитарный корпоративный интерфейс: дерево групп, таблицы материалов, формы с динамическими атрибутами, загрузка файлов, фасеты, админ-таблицы. MVP должен выглядеть аккуратно без дизайнера; переработка стиля возможна позже.

## Решение

UI-кит — **Ant Design 5** (Tree, Table, Upload, Form, русская локаль `ru_RU`). Тема — только через `ConfigProvider` (design tokens). Структура фронта — feature-sliced (code-standards §3.1), серверное состояние — TanStack Query.

## Альтернативы

- **MUI** — сопоставимый набор; выбор пользователя пал на Ant после сравнения (богаче админ-компоненты из коробки, готовая русская локаль).
- **shadcn/ui + Tailwind** — красивее «из коробки», но сложные компоненты (Tree, сложные таблицы) собирать самому — дороже для утилитарного MVP.

## Последствия

- (+) Быстрый старт админ-подобного UI; Tree/Table/Upload/Form покрывают 80% экранов.
- (+) Переработка стиля позже — через design tokens без правки экранов.
- (−) Визуальный язык Ant узнаваем; «сильно кастомный» дизайн позже потребует усилий (принято осознанно).
- (−) CSS-in-JS Ant добавляет вес бандла.
