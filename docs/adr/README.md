# ADR — архитектурные решения

Формат: короткий документ на одно решение — контекст, решение, альтернативы, последствия. Принятые ADR не редактируются; изменение решения = новый ADR со статусом «замещает ADR-XXXX».

Шаблон:

```
# ADR-XXXX: <название>
Статус: предложено | принято | замещает ADR-YYYY
Дата: <дата>
Контекст: <проблема и ограничения>
Решение: <что решили>
Альтернативы: <что рассматривали и почему отклонили>
Последствия: <что это даёт и чем платим>
Ссылки: <concept.md §…, requirements REQ-ID>
```
