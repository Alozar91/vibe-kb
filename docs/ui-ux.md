# UI/UX: реестр экранов и состояний

- **Статус:** рабочий документ (v0.1, 2026-11-20)
- **Основа:** Ant Design 5, русский интерфейс, desktop-first (корпоративный сценарий); утилитарный MVP с темизацией позже (§16 п. 15).
- Назначение: договориться об экранах **до вёрстки**. Компоненты Ant указаны для быстроты, не как ограничение.

---

## 1. Реестр экранов

| № | Экран / маршрут | Назначение | Ключевые компоненты (Ant) |
|---|---|---|---|
| 1 | Вход (`/login`) | Редирект на Keycloak (пароль/Kerberos); своего экрана логина почти нет — только состояние «возврат после ошибки» | Button, Result |
| 2 | **Главный экран** (`/`) — дерево + содержимое группы | Слева дерево групп (Tree), справа таблица материалов группы; breadcrumbs пути; кнопки создания группы/материала | Layout, Tree, Table, Breadcrumb |
| 3 | Карточка материала (`/materials/:id`) | Полная информация: описание, атрибуты, ссылки, статус-панель, версии, родитель | Descriptions, Tabs, Steps/Tag (статус), Popconfirm (переходы) |
| 4 | Создание/редактирование (`/groups/:gid/new-material`, `/materials/:id/edit`) | Форма: название, описание, атрибуты (динамика по справочнику), внешние ссылки, файл (drag&drop), комментарий изменения | Form, Upload.Dragger, Select (типизированные атрибуты) |
| 5 | Просмотр превью (`/materials/:id/preview`) | pdf.js viewer; до готовности — «превью готовится»; без AV — блок | Modal / Drawer, Progress |
| 6 | **Поиск** (`/search`) | Строка, выбор режима (полнотекст/вектор/гибрид/атрибуты), фасеты слева, результаты с подсветкой | Input.Search, Form (фильтры), List/Card, Tag |
| 7 | Права группы (`/groups/:id/access`) | Список пользователей с ролями, выдача/отзыв | Table, Select (пользователи через поиск), Popconfirm |
| 8 | Админка (`/admin/*`) | Разделы: настройки (лимиты, модели, дефолтный чанкер), чанкеры (реестр + перезагрузка), переиндексация, задачи пайплайна, журнал аудита, «документы без текста» | Tabs, Form, Table, Statistic |
| 9 | Профиль (`/me`) | Мои роли по группам, мои материалы (быстрые фильтры) | Descriptions, List |
| 10 | 403 / 404 (`/403`, `*`) | Нет прав / не найдено | Result |

- Экраны 2–6 — ядро MVP; 7–9 — по мере готовности бекенда; админка утилитарная (Table+Form без дизайна).

## 2. Ключевые состояния (сквозные)

| Состояние | Как показываем |
|---|---|
| Нет прав вовсе (ПРВ-5) | Пустое дерево + пояснение «обратитесь к владельцу раздела» (не ошибка) |
| Nav-only предок (ПРВ-2) | Группа в дереве показана, но некликабельна по содержимому (только транзит) |
| Файл на AV-скане (НФТ-4) | Кнопки «скачать/превью» заблокированы с подсказкой «проверка на вирусы» |
| Превью готовится (ПРС-2) | Спиннер + текст; автоповтор запроса |
| Optimistic locking (409) | Модал: «материал изменился» → кнопки «перечитать» / «показать мою версию» (ВЕРС, §7) |
| «Ничего не изменилось» (ВЕРС-2) | Info-сообщение без создания версии |
| Ошибка API (problem+json) | Ант-уведомление с `detail` из ошибки; 401 → редирект на логин |
| Индикатор «родитель обновился» (ВЕРС-4) | Бейдж в карточке: «привязана vN, актуальная vM» |
| Идет индексация (ЧНК-1) | Статус индексации версии: в очереди / извлечение / чанкование / готово; ошибка шага — с текстом |

## 3. Правила UX

- Кнопки, недоступные по роли, **скрываются** (не дизейблятся) — кроме случаев, когда полезно показать существование операции (тогда дизейбл + tooltip с причиной) — решаем по экрану, правило: скрываем по умолчанию.
- Деструктивные действия (soft-delete, архив) — с Popconfirm и указанием последствий («восстановление невозможно»).
- Переходы статуса — только валидные кнопки из данных API (машина состояний бекенда — единственный источник, `code-standards.md` §2.2).
- Пагинация таблиц — серверная (`limit/offset`, api-spec §1).
- Все тексты — русские; термины — по глоссарию концепции (§2).

## 4. Вне MVP

Тёмная тема (токены готовы в Ant, включим позже), мобильная адаптация, сохранённые запросы и экспорт (§16 п. 16 — отклонено), тегирование файлов на превью.
